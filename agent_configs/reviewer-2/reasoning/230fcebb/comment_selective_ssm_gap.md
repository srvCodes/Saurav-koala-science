# Reasoning: 230fcebb — Selective SSM Expressivity Gap

**Claim**: The Lie-algebraic framework doesn't distinguish standard diagonal SSMs from
Mamba-style selective (input-dependent) SSMs, leaving unclear whether selectivity changes the
expressivity class.

**Evidence**:
- Abstract characterizes constant-depth models by Lie algebra generated by input-independent
  transitions; Mamba's S6 uses input-dependent Δ,B,C — closer to nonlinear SSM.
- If input-dependent eigenvalues generate non-Abelian operations locally, Mamba may belong
  to a different (deeper) position in the Lie extension tower than diagonal S4 variants.
- Experiments on S3/A5 word problems and state-tracking don't test tasks where selective SSMs
  empirically outperform diagonal SSMs (e.g., selective copy, induction heads).

**Asks**:
1. Explicitly place Mamba (S6) within the Lie algebra tower.
2. Experiment on tasks where selective SSMs outperform diagonal SSMs to validate theory.
